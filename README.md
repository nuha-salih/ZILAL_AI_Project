## النموذج الحراري

```
C · dT_in/dt = UA(T_out − T_in) + Q_solar + Q_internal − Q_cool
T_next = T + (dt/C)·[UA(T_out − T) + Q_solar + Q_internal − Q_cool],   dt = 900 s   (أويلر الصريح)
Q_solar    = A_window · G_facade · SHGC · (1 − shading)
Q_internal = N·q_person + P_lighting + P_equipment      (الإضاءة والأجهزة عند الإشغال فقط)
E_HVAC_kWh = (Q_cool / COP) · dt / 3 600 000,   0 ≤ Q_cool ≤ قدرة المكيّف
```

- **الاستقرار:** يُرفض أي إعداد يحقق dt·UA/C ≥ 0.5.
- **الاتجاه:** `G_facade = GHI × f(hour)` حيث `f = d + (peak − d)·exp(−½((h − h0)/σ)²)`؛ الشرق ذروته ~08:00، الغرب ~16:00 (peak=1)،
  الجنوب ذروته منخفضة صيفاً (0.30) عند الظهر، و d = 0.15 للإشعاع المنتشر. **هذا تقريب لتعرّض الواجهة وليس محرك هندسة شمسية.**
  يمكن تجاوزه بأعمدة `g_east_wm2` / `g_west_wm2` / `g_south_wm2` في ملف الطقس.
- **قدرة التبريد في الاستراتيجيات:** طلب «يوصل الغرفة إلى الهدف خلال الخطوة» يُقيَّد بقدرة المكيّف، فتختلف النتائج بسبب منطق القرار فقط.

## الاستراتيجيات

| | المنطق |
|---|---|
| A ثابتة | تشغيل 06:00–18:00 بغض النظر عن الإشغال (خط الأساس) |
| B جدول | تشغيل أثناء الجدول المعلن فقط، بلا تبريد مسبق |
| C قواعد | تبريد عند الإشغال وتجاوز الهدف + هامش؛ عند الخلو لا تبريد إلا فوق حد وقائي (32°م افتراضياً) |
| D تنبؤي | يحسب بنموذج RC قدرة التبريد اللازمة للوصول للهدف عند الحضور، ويبدأ في أبعد لحظة ممكنة؛ يرفع الهدف 0.5°م أثناء الإشغال (داخل نطاق الراحة) |

## الافتراضات (كلها غير مقاسة)

مساحة 60 م²، 30 طالباً، نوافذ 12 م² (اتجاه واحد)، SHGC=0.60، UA≈3.4 W/K لكل م² (≈204 W/K)،
سعة حرارية 150 kJ/K لكل م²، 75 W للشخص، إضاءة 12 W/م²، أجهزة 300 W، قدرة تبريد 15 kW حراري، COP=3.0،
هدف راحة 24°م ± 1.5، حرارة ابتدائية 24°م. **ليست خصائص قاعة فعلية في جامعة نجران.**

## المقاييس

الطاقة، الساعات خارج نطاق الراحة (أثناء الإشغال فقط)، طاقة وقت الخلو، الطاقة «غير الضرورية» (خارج نافذة تهيئة مسبقة 4 ساعات)،
والتوفير = (E_A − E)/E_A × 100 (أساس صفري → 0). **توفير مع مخالفة راحة > 5٪ من وقت الإشغال لا يُعدّ توفيراً صالحاً.**

## صدق علمي وحدود

- الطقس المرفق **اصطناعي مُحاكى** وليس قياسات نجران؛ ارفع CSV (`timestamp, outdoor_temp_c, solar_irradiance_wm2`) لبيانات حقيقية.
- لا توجد قياسات ولا معايرة ولا تحقق ميداني؛ كل الأرقام نتائج محاكاة وليست وفورات فعلية للجامعة.
- التحكم التنبؤي يفترض توقعاً مثالياً للطقس والإشغال.
- Random Forest (اختياري، يدرَّب عند الضغط على الزر) يتعلم من بيانات ولّدها المحاكي نفسه؛ دقته تقيس تقليد المحاكي فقط ولا يُستخدم في التحكم.
- نموذج منطقة واحدة؛ بلا رطوبة أو تهوية أو حرارة كامنة؛ COP وقدرة المكيّف ثابتتان.
- بيانات «تحدي ZILAL الأخضر» توضيحية؛ ترتيبها = تحسّن مُطبَّع × معامل راحة (ليس الطاقة الخام).
- السيناريو الرابع «الإفراط في التبريد» مُنفَّذ كحالة محاضرة قصيرة داخل جدول طويل (يقيس الهدر وقت الخلو، لا تبريداً تحت نقطة الضبط).
